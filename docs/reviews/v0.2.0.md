# Quality review — v0.2.0

## Outcome

**Validated for the stated release boundary.** The release closes the navigation-and-context gap without expanding into a speculative call graph. The principal architectural additions are explicit declaration and relationship-occurrence locations, editor-event lifecycle control, autoload metadata, and a separate exact text-scene evidence stage.

## Highest-priority findings and resolutions

- **Observed usability gap:** graph findings could not be followed to source efficiently. Resolved with script, property, signal, method, inner-class, and exact dependency-occurrence actions carrying one-based locations and safe script-level fallback behavior.
- **Observed scale/navigation gap:** semantic filters did not provide fast lookup. Resolved with non-destructive search, previous/next focus, and path/member/scene matching.
- **Observed freshness gap:** timed polling was a poor default for editor work. Resolved with default-on debounced editor synchronization; timed scanning remains default-off.
- **Observed architectural-context gap:** autoload and scene attachments were absent. Resolved with snapshot-v2 records and exact `.tscn` evidence.
- **Risk:** filesystem export events could create refresh loops. Controlled with bounded self-event suppression, one-shot debounce, non-overlap, and one pending-refresh state.
- **Risk:** scene parsing could become an unbounded resource graph. Controlled by a separate bounded text-only stage and an exact direct-node-attachment boundary.
- **Risk:** duplicated scene evidence could drift between top-level and node records. Controlled by validator checks for duplicate, orphaned, mismatched, and missing per-node evidence.

## Executed evidence

- Static integrity: 438 checks passed after the final feature implementation; optional `gdlint` and `gdformat` checks were skipped because the tools were unavailable.
- Runtime matrix: all eight gates passed under each supplied Godot 4.3, 4.4.1, 4.5.2, 4.6.3, and 4.7 Linux executable.
- Visual evidence: eight purpose-specific 900×1100 screenshots were rendered with Godot 4.7.
- Schema evidence: generated showcase JSON validates against snapshot-v2 when the optional Python `jsonschema` dependency is available in the validation environment.

See [VALIDATION.md](../VALIDATION.md) and the [compatibility matrix](../validation/v0.2.0-compatibility-matrix.md).

## Open evidence gaps

Independent unfamiliar-user comprehension testing remains unexecuted. Godot 4.0–4.2 and non-Linux compatibility remain unclaimed. Binary scenes, dynamic/transitive scene dependencies, background scanning, general call-graph inference, and runtime behavior remain outside the accepted boundary.
