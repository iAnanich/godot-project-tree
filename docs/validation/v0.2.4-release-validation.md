## Defect found and corrected during validation

Godot 4.3 initially attempted to import the large PNG/WebP documentation tree and terminated abnormally. `docs/asset_store/.gdignore` now makes the repository media explicitly non-importable. Static validation requires this boundary, and the complete compatibility matrix was rerun successfully afterward.

The new media helper plugin also changed the repository-wide showcase test input count. The test was corrected to exclude the media-only fixture and disabled capture helper, preserving the established showcase fixture boundary rather than accepting an incidental count change.

## Release-integrity evidence

Generated editor caches, documentation import sidecars, temporary captures, and `dist/` outputs are excluded from release inputs where appropriate.
