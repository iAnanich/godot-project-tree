## Media compatibility finding

An initial Godot 4.3 import attempted to process the new repository media and terminated abnormally. The final design places the complete `docs/asset_store/` tree behind `.gdignore`; the full 4.3–4.7 matrix above was rerun after that correction and passed. The media remains available in Git and release source archives but is not an importable Godot resource tree.

## Qualifications

- Claimed evidence is Linux x86_64 only and limited to the supplied binaries.
- `gdlint` and `gdformat` could not be installed or executed in the offline validation environment. Their pinned pre-commit and GitHub Actions configuration remains in the repository; Godot parser/import and runtime execution were authoritative here.
- No claim is made for Godot 4.0–4.2, future versions, non-Linux editors, C# analysis, binary scenes, general inferred call graphs, independent accessibility testing, or an independent human security audit.
