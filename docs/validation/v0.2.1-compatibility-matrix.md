## Static/tool qualification

The compatibility-matrix runs completed 518 project-owned checks. The final post-review static pass completed 521 checks after adding the screenshot-review artifact, repository ignore contract, and its required-file assertion; no runtime implementation changed after the five-engine matrix. `gdlint` and `gdformat` were not installed and were explicitly reported as skipped optional commands. Godot parser/import and runtime tests passed on every claimed version.

## Visual qualification

The automated visual gate rendered the selected-scope state under Xvfb on every engine. The release's four 900×1100 Godot-rendered screenshots were generated with Godot 4.7 and manually inspected for state correctness, clipping, scope labels, focus controls, and graph visibility. This is rendering evidence, not unfamiliar-user comprehension or accessibility-conformance evidence.

## Unclaimed environments

No claim is made for Godot 4.0–4.2, future Godot versions, non-Linux editors, C# analysis, exported games, binary scenes, or screen-reader behavior.
