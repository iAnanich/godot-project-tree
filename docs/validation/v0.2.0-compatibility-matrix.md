## Qualification

- This matrix supports only the named supplied Linux builds.
- Godot 4.0–4.2, other operating systems, future Godot versions, C# analysis, and exported-game runtime use remain untested and unclaimed.
- `gdlint` and `gdformat` were not installed in the validation environment; the static runner reported those optional checks as skipped. Godot parser/import execution was performed under every listed engine.
- Screenshots are rendering evidence, not unfamiliar-user comprehension evidence.
